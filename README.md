# AutoData

AutoData es un proyecto web realizado para el módulo de Lenguajes de Marcas y Sistemas de Gestión de Información (LMSGI), del curso 2026-2027.

## Descripción del proyecto

La página web permite consultar información sobre diferentes modelos de coches, incluyendo características como el motor, la potencia, el consumo y el combustible.

## Contenido de la web

- **Tema 2:** página de inicio, catálogo de vehículos y fichas individuales.
- **Tema 3:** tablas de información y galería multimedia de vehículos.
- **Tema 4:** formulario HTML con validación de datos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git y GitHub
- GitHub Pages

## Publicación

Página web: https://miquel2402.github.io/AutoData/

Repositorio: https://github.com/Miquel2402/AutoData

## Limitaciones

GitHub Pages permite publicar páginas estáticas, pero no ejecuta código de servidor. Por tanto, la validación HTML del formulario no sustituye la validación que necesitaría un servidor para procesar datos de forma segura.
