# Ficha de procedencia y licencias de recursos

## Proyecto AutoData

Este documento recoge la información sobre las imágenes utilizadas en la galería de vehículos del proyecto AutoData.

### 1. Recursos utilizados

| Imagen | Vehículo | Resoluciones |
|---|---|---|
| toyota-corolla | Toyota Corolla | 480, 768 y 1920 px |
| seat-leon | SEAT León | 480, 768 y 1920 px |
| volkswagen-golf | Volkswagen Golf | 480, 768 y 1920 px |

### 2. Procedencia de las imágenes

Las imágenes se han incorporado al proyecto mediante un paquete de recursos descargado y extraído previamente.

La procedencia original de las fotografías debe comprobarse en la fuente de descarga.

### 3. Licencias y derechos de uso

No se asigna ninguna licencia Creative Commons ni de dominio público sin disponer de una fuente que lo confirme.

Antes de publicar el proyecto, se debe verificar la licencia original de cada fotografía y registrar:

- Autor o propietario de la fotografía.
- Página web de procedencia.
- URL original.
- Licencia de uso.
- Condiciones de atribución.

### 4. Organización de los archivos

Todas las fotografías están guardadas en:

`assets/images/`

Cada vehículo dispone de tres versiones para adaptar la carga de imágenes a diferentes tamaños de pantalla.

### 5. Conclusión

El proyecto AutoData utiliza imágenes en diferentes resoluciones para mejorar la experiencia de navegación. También se documenta la procedencia y los derechos de uso para garantizar una publicación responsable de los recursos multimedia.
