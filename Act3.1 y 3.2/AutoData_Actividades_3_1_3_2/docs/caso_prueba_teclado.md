# Caso de prueba — Tabla AutoData

**Objetivo:** comprobar que la tabla tiene encabezados comprensibles y se puede utilizar con teclado.

1. Abrir `tablas/tabla.html` en un navegador.
2. Usar Tab para recorrer los elementos interactivos de la página. Nota: las celdas normales de una tabla no suelen recibir el foco con Tab de forma individual; para comprobar la asociación semántica, usar un lector de pantalla o las herramientas de accesibilidad del navegador.
3. Confirmar que los enlaces, si se añaden, muestran un contorno de enfoque visible.
4. Comprobar que cada fila tiene la marca y modelo identificados por `scope="row"` y cada columna tiene su encabezado por `scope="col"`.
5. Abrir el validador W3C y validar el archivo.

| Comprobación | Resultado esperado | Resultado real |
|---|---|---|
| Estructura HTML | Sin errores de marcado | Completar después de validar |
| Encabezados de columna | Cada dato tiene su contexto de columna | Completar después de probar |
| Encabezados de fila | Se identifica cada modelo | Completar después de probar |
| Enfoque visible | Los elementos interactivos enfocados se distinguen | Completar después de probar |

No marques las pruebas como superadas hasta ejecutarlas realmente.
