# Decisiones técnicas de la galería AutoData

## 1. Objetivo

El objetivo de esta práctica es crear una galería de imágenes de vehículos que sea accesible, adaptable a diferentes dispositivos y que utilice metadatos estructurados.

## 2. Organización de las imágenes

Se han seleccionado tres modelos de vehículos:

- Toyota Corolla.
- SEAT León.
- Volkswagen Golf.

Cada vehículo dispone de tres versiones de imagen:

- 480 píxeles: dispositivos móviles.
- 768 píxeles: tabletas.
- 1920 píxeles: pantallas grandes.
